## 🚀 Projects

- 🔍 **[Lawlatt](https://github.com/Abhinav-0709/lawlatt)** *(in progress)*
  AI safety and security evaluation platform — tests LLMs against jailbreak, prompt injection, hallucination, prompt leakage, and toxicity attacks using curated datasets. Weighted risk-scoring engine outputs an A+–F safety grade with JSON/Markdown/PDF reports.

- 📄 **[LintIt](https://lintit.abhinav.sbs)** *(in progress)*
  Local-first, no-signup resume builder with real-time WYSIWYG preview. Integrates Gemini to score resumes against job descriptions and return structured improvement feedback. 6 customizable templates with print-optimized export.

- 🏫 **[Campus Copilot](https://github.com/Abhinav-0709/campus-copilot)**
  Full-stack campus ERP with a 21-model PostgreSQL schema and a hybrid auth system (Supabase Auth + custom role-validation guard) enforced across student/faculty/admin routes. Includes a RAG-based chatbot with a keyword-matching fallback.

- 🧭 **[RepoNavigator AI](https://github.com/Abhinav-0709/reponavigator-ai)**
  Two-stage AI pipeline for repository structure analysis — a Groq-hosted model generates a research plan from a heuristically-ranked file structure, passed to Gemini to produce an architecture summary. Tested against large repos including Google DeepMind and Fastly.

- 🚁 **[Nexus Relief](https://github.com/Abhinav-0709/nexus-relief)**
  Hierarchical multi-agent disaster-response simulation — a Gemini-powered Commander agent dispatches autonomous drone units via function calling, with a human-in-the-loop override tool to interrupt agent decisions mid-simulation.
